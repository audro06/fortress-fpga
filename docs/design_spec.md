# 포트리스 설계 사양 (시뮬레이터 기준, 2026-11-03)

- 시뮬레이터: https://claude.ai/artifact/FjrCj6MJnH1xUdcv3n9Ped (페이지 맨 아래 "보드 이식 파일"에서 ROM·Verilog를 다시 받을 수 있음)
- 보드 이식 파일 묶음: fortress_rtl.zip (trajectory.v, tb_trajectory.v, vel/muzzle/cannon/glyph/msg ROM .mem, params.vh, glyph_ids.vh)

## 1. 게임 흐름
- 첫 턴: 두 플레이어 모두 이동만 해요 (P1 → P2).
- 이후 턴: 조준(각도 30~90°, 파워 1~16 왕복 게이지) → 발사 → 결과 → 이동(제한 없음, 5로 종료) 순서예요.
- 숨김: 내 차례엔 상대 탱크가 안 보이고, 마지막으로 본 자리에 `?`만 떠요. 누군가 발사하는 순간 서로 위치가 드러나요. CPU도 마지막으로 본 위치만 알아요.
- 화면: LCD는 전장 화면 하나예요. 아랫줄은 땅(탱크·벽), 윗줄은 차례인 쪽 HUD예요.
- 바람: 기본은 없어요. 돌풍 이벤트 때만 불어요.

## 2. 맵
- 16칸 중 P1 0~5칸, P2 10~15칸을 쓰고, 탱크는 몸통+대포 2칸이에요.
- 가운데 벽은 7·8칸이에요. 판마다 낮은 벽 2개이거나 한쪽이 2층 탑이에요.
- 벽은 온전 → 금 감 → 잔해 → 무너짐 순서로 부서지고, 아래가 무너지면 윗 블록이 떨어져요.

## 3. 포탄 (무제한 선택, 키 1~4, 같은 키를 다시 누르면 일반)
| 포탄 | 피해 (직격/근접/스침) | 특징 |
|---|---|---|
| 일반 | 35 / 20 / 10 | 근접 4px, 스침 8px |
| 두 발 | 20 / 12 / 6 | 두 발 연속, 둘째는 파워 ±1 |
| 넓은 폭탄 | 22 / 16 / 8 | 근접 7px, 스침 13px |
| 얼음 | 피해 없음 | 탄착 칸 ±1 안의 탱크가 다음 이동 차례에 못 움직임 |
| 불 | 30 / 15 / 0 | 명중하면 자기 +15, 빗나가면 자기 -15 |

## 4. 3턴마다 이벤트 (2턴 유지, 스텝모터 룰렛으로 선택)
- LAVA: 양 진영에 용암 칸이 하나씩 생겨서 그 칸으로 이동할 수 없어요.
- LOW-G: 중력 18 → 11이 돼요.
- GUST: 바람이 ±3~5로 불어요.
- QUAKE: 탱크가 ±1칸 밀리고, 벽이 한 단계씩 부서져요.
- FOG: 비행 중인 포탄이 안 보여요.
- METEOR: `!`로 표시한 3칸에 2턴 뒤 유성이 떨어져요(20).

## 5. 탄도 (하드웨어와 비트 단위로 같음)
- 단위는 1/256 픽셀 정수예요. 매 프레임 틱(30 Hz)마다 `vx += wind; vh -= grav; x += vx; h += vh` 순서로 계산해요.
- 화면 좌표는 `px = x >>> 8`, `py = 15 - (h >>> 9)`예요.
- 판정 순서: 맵 밖(px < -4 또는 > 84) → 벽 → 탱크 직격(py ≥ 11, 발사 후 8틱 동안 자기 탱크 제외) → 땅(h ≤ 0)
- 시작값은 속도 ROM `(각도-30)*16 + (파워-1)` → {vx, vh}, 포구 ROM `각도-30` → {x 오프셋, h0}에서 읽어요.
- trajectory.v는 시뮬레이터 정답 104개와 일치해요. Python 비트 모델로 대조했어요. 실제 Verilog 시뮬레이션(tb_trajectory.v)은 아직 안 돌렸어요.

## 6. LCD CGRAM 슬롯 (용도 고정)
| 슬롯 | 게임 화면 | 타이틀 |
|---|---|---|
| 0 / 1 | P1 몸통 / P1 대포(각도별, cannon_rom) | 같음 |
| 2 / 3 | P2 몸통 / P2 대포(비트 반전) | 같음 |
| 4 | 금 간 벽 | 두 발 아이콘 (게임 끝 화면: 트로피) |
| 5 | 잔해 | 넓은 폭탄 아이콘 |
| 6 | 용암 | 얼음 아이콘 |
| 7 | 포탄 / 폭발(6프레임) / 유성 | 불 아이콘 |

- 내장 문자로 슬롯을 아껴요: 온전한 벽 8'hFF, 궤적 8'hA5, 화면 위 `^`, 지난 탄착 `.`, 숨은 상대 `?`, 유성 경고 `!`, 넓은 폭발 양옆 `*`
- LCD 연출: 흔들림은 표시 이동 명령(8'h18/8'h1C), 승리 깜빡임은 표시 ON/OFF(8'h08/8'h0C)로 해요.

## 7. 장치 매핑 (변경점)
- 7세그: P1 HP | 다음 이벤트까지 남은 턴 또는 E1~E6 | P2 HP
- 스텝모터: 풍향계 대신 이벤트 룰렛으로 써요.
- DIP: 1 특수 포탄 / 2 P2=CPU / 3 CPU 고수 / 4 3턴 이벤트 / 5 발사 후 이동 / 6 체력 200 / 7 효과음 / 8 가운데 벽

## 8. 구현 범위 제안
- 필수: 탄도, 고정 슬롯 LCD, 턴·이동·숨김, 일반+두 발+얼음, 벽, 7세그·서보·LED·Piezo
- 확장: 불·넓은 폭탄, 이벤트(룰렛 + 지진·저중력·유성부터), CPU(상대 칸 → 각도·파워 표 + LFSR 오차)
